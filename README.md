## 🚀 About Me

I'm a passionate UI Developer with **5+ years of experience** crafting beautiful, responsive, and accessible web experiences. I specialize in transforming complex design concepts into functional, user-friendly interfaces that work seamlessly across all devices and platforms.

**My Expertise:**
- 🎨 **Frontend Development**: HTML5, CSS3, SCSS/SASS, JavaScript (ES6+)
- ⚛️ **Frameworks & Libraries**: React, React Native, Alpine.js, jQuery
- 🎯 **Styling**: Bootstrap, Tailwind CSS, Materialize, PostCSS
- 📱 **Mobile Development**: Cross-platform apps, React Native, Apache Cordova
- ♿ **Web Accessibility**: WCAG 2.1 compliance, ARIA implementation
- 🛠️ **Tools**: Git, Gulp, Figma, Adobe XD, Sketch, InVision
